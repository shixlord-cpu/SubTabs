# SideTabs examples

This folder is a playground for vertical SideTabs. Enable the feature in
Settings → Familia → SideTabs, then open any file here and click a side tab
to jump to that section.

## Setup

Turn SideTabs on, keep them expanded, and pick left or right next to the flag.

## Languages

HTML, Angular, tests, CSS, Vue, JavaScript, Java, Kotlin, C#, Python, Go,
PHP, Rust, SQL, and Markdown each have a complete example file.
