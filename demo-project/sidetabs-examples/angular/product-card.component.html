Draft

Activity

  1. Load

    Load the current snapshot from the remote catalog.

  2. Refresh

    Refresh stale values without resetting the open view.

  3. Save

    Persist the draft and keep the previous revision.

  4. Validate

    Check required fields before the next transition.

  5. Apply Discount

    Apply a percentage discount and round to cents.

  6. Clear Discount

    Remove the active discount and restore list prices.

  7. Select

    Remember the row the operator last focused.

  8. Deselect

    Drop the current selection and return to the list.

  9. Filter

    Narrow the visible rows by the active query.

  10. Sort

    Order rows by the requested column and direction.

  11. Page

    Move the window to another slice of the result set.

  12. Retry

    Repeat the last failed request with the same payload.

  13. Cancel

    Abort the in-flight request and restore the idle flag.

  14. Archive

    Move a finished record out of the working set.

  15. Restore

    Bring an archived record back into the working set.

  16. Duplicate

    Copy a record and assign a fresh identifier.

  17. Merge

    Fold incoming changes into the local draft.

  18. Split

    Separate a combined line into independent entries.

  19. Assign

    Attach the record to the current operator.

  20. Release

    Detach the record so another operator can take it.

  21. Notify

    Queue a status message for the surrounding shell.

  22. Audit

    Append an audit note without changing business fields.

  23. Export Rows

    Build a flat export of the rows currently in view.

  24. Import Rows

    Accept a flat import and reject unknown columns.

  25. Summarize

    Reduce the working set to totals and counts.

  26. Reset

    Return the draft to the last confirmed snapshot.
